# Smart C&D Material Quality Evaluation System

A web-based tool for evaluating the quality and reuse suitability of Construction & Demolition (C&D) waste materials using Indian Standard (IS) code parameters.

## Features

- Brick Quality Evaluation
- Aggregate Quality Evaluation
- Reinforcement Bar (Rebar) Evaluation
- Weighted Quality Scoring
- Sample Photo Upload
- Evaluation History Tracking
- Excel Export

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- SheetJS (XLSX)

## Supported Standards

- IS 1077
- IS 12894
- IS 2185
- IS 4139
- IS 383
- IS 2386
- IS 1786
- IS 432
